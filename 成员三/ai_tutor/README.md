# R语言AI助教本地模拟版

这是基于成员一课程资料的本地演示程序。真实HTTP接口已经实现；回答由关键词、固定规则与教学案例组成，不调用大模型，也不运行提交的R代码。

## 现在怎么用

1. 双击本目录的 `start.cmd`。看到 `Ready` 表示启动成功；如果提示8000端口已经占用，先打开下面的网址确认已有服务。
2. 浏览器打开 [新版首页](http://127.0.0.1:8000/#/home)，点击“AI问答”，再点“缺失值与均值”。回答后点击“例题”或“易错点”连续学习；首条回答出现后隐藏示例入口。
3. 从导航进入“代码纠错”，粘贴代码与报错后发送；也可以在问答里点击“添加代码”。收起代码区后不提交残留内容。“内容来源”和“参考输出”默认折叠，“复制代码”复制参考示例。
4. 综合练习先显示解题提示，点击“参考答案”切换。知识地图按八个单元展示课程，点击知识点或前置知识会直接进入讲解。桌面课程侧栏可收起，手机使用抽屉。
5. “学习记录”可返回某条对话、导出或清空当前浏览器记录；刷新恢复记录，切换视图保留未发送草稿（草稿不会保存到刷新后）。右上角“更多”同时提供导出、清空、接口文档及版本说明。导出文件包含提问和代码，分享前自行检查。
6. 用完后双击 `stop.cmd`。脚本只停止它启动且身份核对一致的本项目进程，不关闭其他占用端口的程序。

本轮已安装当前电脑需要的依赖。换电脑或重新创建环境时，先安装Python 3.12（含Python Launcher），双击 `setup.cmd`，安装成功后再双击 `start.cmd`。首次安装需要联网；安装完成后，课程网页及模拟问答不依赖网络。

FastAPI交互文档：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)。默认Swagger页面使用外部静态资源，首次打开需网络；原始接口定义 [openapi.json](http://127.0.0.1:8000/openapi.json) 可离线访问。接口操作的详细说明见上一级的 `接口说明.md`。

## 运行范围和能力限制

- 默认只监听 `127.0.0.1:8000`。这是当前电脑的地址，不是公网地址，手机和其他同学的电脑不能直接用它访问。
- 包含43个知识条目、24道问答、14个错误案例、95条知识关系。代码换行和来源定位来自原文；没有重新运行R代码或逐页核验PDF。
- 精确收录问题与已知错误案例优先匹配；关键词检索支持常见同义词。陌生问题、未知代码模式可能返回“未找到可靠匹配”，这是模拟版的正常限制。
- 错误输出是参考案例，不承诺自动修好任意代码。代码标识符区分大小写，参考修正中的变量和数据需按实际任务调整。
- 追问支持例子、易错点和练习；保留最近6轮请求上下文，不具有大模型式自由对话理解。
- 同一浏览器保留最多100条记录；服务端不保存会话数据库。不要把session_id当成用户认证。
- Excel的“39条已运行、4条待实测”记录已保留在导入报告中，本应用不将任何输出标为本次实测结果。

## 给成员二

前端可直接使用相对路径 `/api/chat` 等接口。独立开发服务器只放行 `http://localhost:5173` 和 `http://127.0.0.1:5173`；更换端口需要显式调整后端CORS配置。不要从 `file://` 双击HTML作为联调方式。

接口实现位于 `app/main.py`，资料检索和模拟回答位于 `app/engine.py`，页面位于 `static/`。以后替换回答模块接入真实模型，尽量保留请求与响应结构。

## 给维护者

在本目录打开PowerShell，执行以下命令：

```powershell
# 自动接口与资料回归测试
.\.venv\Scripts\python.exe -m pytest -q

# 成员一更新资料后重新导入，再重启服务并测试
.\.venv\Scripts\python.exe scripts/import_data.py

# 按实际运行接口重新生成上一级的接口说明
.\.venv\Scripts\python.exe scripts/generate_api_docs.py
```

依赖锁定在 `requirements.txt`，请使用项目虚拟环境，不要求修改全局Python。启动异常查看 `.runtime/server.err.log`；该目录、虚拟环境及临时文件都被Git忽略。

浏览器验收脚本位于 `tests/browser_check.js`，由Playwright CLI的 `run-code --filename` 执行。截图与下载验证产物使用工作区根目录的 `output/playwright/`，不纳入版本控制。浏览器验收命令（在工作区根目录执行，需 Node.js / npx）：

```powershell
npx.cmd --yes --package @playwright/cli playwright-cli -s=r-tutor-v2 open http://127.0.0.1:8000
npx.cmd --yes --package @playwright/cli playwright-cli -s=r-tutor-v2 run-code --filename "成员三/ai_tutor/tests/browser_check.js"
```

脚本清空独立测试浏览器中的学习记录，请勿连接个人常用浏览器执行。断开验收脚本 `tests/browser_offline.js` 须在测试页面已加载、项目服务已停止时运行；随后使用 `start.cmd` 恢复服务。停止脚本兼容 Windows PowerShell 与 PowerShell 7，并核对父进程身份及项目 Python 子进程。
