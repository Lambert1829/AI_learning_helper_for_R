mean 中的 na.rm 怎么用？

计算均值时，跳过缺失值。

设置 na.rm = TRUE，会在计算时移除缺失项，不修改原始向量。

例题易错点内容来源 · K06
R · 代码纠错
# 判断缺失值
x <- c(2, NA, 4)
x == NA

# 参考修正
is.na(x)

使用 is.na() 检查缺失。
