## 学习目标

- 能够在填补前用标记列记录哪些值原本缺失，保证处理过程可追溯。

## 先备检查

1. `mean(c(60, NA, 90))`的结果是什么？预期回答为`NA`。
2. `d[!is.na(d$score), ]`保留哪些行？预期回答为`score`不缺失的行。

## 直观理解

缺失值和异常值都没有“万能”的处理方法，每种做法都在用一点信息换取方便。整表删除最简单，但可能因为一个无关列的空白就丢掉整行有效成绩；用均值填补让数据看起来完整，却会让波动变小、结论显得更确定。比较稳妥的做法是：先统计缺了多少、缺在哪里，处理前保存一个“原本缺失”的标记，并在报告中写明规则。异常值也一样，先按规则找出来，再回到原始记录判断它是录入错误还是真实的极端情况。

## 为什么

1. 为什么`na.omit(d)`可能删掉过多的行？它删除任一列含缺失的行，分析成绩时备注列的空白也会让这一行被删掉。
2. 为什么均值填补会低估波动？填进去的值都等于均值，不贡献任何离差，标准差会变小。
3. 为什么不能直接删除超出范围的值？超出范围可能是单位错误或录入错误，修正后仍是有效数据；直接删除会丢失信息，也无法追溯。

## 基础例题

用均值填补缺失的成绩，并新增一列记录哪些值是填补的。

独立脚本见[K28_example_01.R](../ai_tutor/content_assets/code/K28_example_01.R)。

```r
d <- data.frame(id=1:3,score=c(80,NA,100))
d$was_missing <- is.na(d$score)
d$score[d$was_missing] <- mean(d$score,na.rm=TRUE)
print(d)
```

### 预期输出（待R实测）

```text
  id score was_missing
1  1    80       FALSE
2  2    90        TRUE
3  3   100       FALSE
```

### 逐步讲解

1. 先生成标记列，记住第2行原本缺失。
2. 用有效成绩80和100的平均值90填补缺失。
3. 填补后成绩列完整，但标记列保留了处理痕迹，后续分析可以排除或单独检查这些行。

## 应用例题

五条成绩记录中，备注列有多处空白，成绩只缺一个。比较整表删除和只按成绩列删除，看各自保留多少有效成绩。

独立脚本见[K28_example_02.R](../ai_tutor/content_assets/code/K28_example_02.R)。

```r
d <- data.frame(id = 1:5, score = c(80, NA, 95, 70, 88),
                note = c(NA, "late", NA, NA, "ok"))
print(nrow(na.omit(d)))
print(sum(complete.cases(d)))
kept <- d[!is.na(d$score), ]
print(nrow(kept))
print(round(mean(kept$score), 2))
```

### 预期输出（待R实测）

```text
[1] 1
[1] 1
[1] 4
[1] 83.25
```

### 逐步讲解

1. `na.omit(d)`只剩1行，因为备注列的空白也会导致删行。
2. `complete.cases(d)`判断每一行是否完整，结果同样只有1行。
3. 只按成绩列筛选，保留了4条有效成绩。
4. 基于这4条成绩计算平均分为83.25。

分析成绩时应只检查与成绩有关的列。备注为空不影响成绩的有效性，整表删除会让样本从4条缩减到1条，结论也会随之改变。

## 易错案例

为了让数据完整，用均值填补两个缺失值，却没有注意到波动被明显低估。

```r
x <- c(60, NA, NA, 90, 75)
filled <- x
filled[is.na(filled)] <- mean(x, na.rm = TRUE)
print(filled)
print(round(c(before = sd(x, na.rm = TRUE), after = sd(filled)), 2))
```

### 实际错误或异常结果（待R实测）

```text
[1] 60 75 75 90 75
before  after 
 15.00  10.61 
```

参考修正不急于填补，先如实报告样本数、缺失数和基于有效值的统计量。

```r
x <- c(60, NA, NA, 90, 75)
print(c(n = length(x), missing = sum(is.na(x)), mean = mean(x, na.rm = TRUE)))
```

### 预期输出（待R实测）

```text
      n missing    mean 
      5       2      75 
```

填补后标准差从15.00降到10.61，并不是因为数据变得更稳定，而是因为填入了两个“恰好等于均值”的数。如果确实需要填补，应在报告中说明方法，并用标记列区分原始值和填补值。

## 完整练习

六名学生的成绩中有一个缺失，另有102分和-5分两个超出0到100分范围的值。要求分别标记缺失和超出范围的记录，列出需要复核的行，并用剩余的有效成绩计算有效人数和平均分。

提示判断超出范围时要先排除缺失，否则标记列也会出现`NA`。

独立脚本见[K28_exercise.R](../ai_tutor/content_assets/code/K28_exercise.R)。

```r
d <- data.frame(id = 1:6, score = c(78, 85, 102, NA, 91, -5))
d$missing <- is.na(d$score)
d$out_of_range <- !d$missing & (d$score < 0 | d$score > 100)
print(d[d$missing | d$out_of_range, ])
clean <- d$score[!d$missing & !d$out_of_range]
print(c(valid = length(clean), mean = round(mean(clean), 2)))
```

### 预期输出（待R实测）

```text
  id score missing out_of_range
3  3   102   FALSE         TRUE
4  4    NA    TRUE        FALSE
6  6    -5   FALSE         TRUE
valid  mean 
 3.00 84.67 
```

评分共10分，缺失标记得2分，范围标记正确排除缺失得3分，复核清单得2分，有效统计得3分。常见错误是把范围条件写成`d$score < 0 | d$score > 100`，第4行的标记会变成`NA`，复核清单中多出一行全为`NA`的记录。
